# Marbas user guide

Marbas is a two-panel file manager for the terminal, driven from the keyboard.
Each chapter covers one part of it: a few sentences, a table of keys and the
rules that qualify them.

In every table of keys, *Key* is the key to press and *Alternative* a second
key that does the same, for a terminal or a desktop that keeps the first one
for itself. What each platform keeps is collected in
[Differences between platforms](16-platforms.md).
